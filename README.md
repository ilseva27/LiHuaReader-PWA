# 麗華小說 iPhone PWA v1.0.2 — 語音同步修正版

這版在 v1.0.1 的基礎上，修正三個問題：

1. **第一次按耳機無聲**：首次朗讀以小說正文的短片段啟動 iOS 語音引擎；如引擎仍未啟動，可直接再按耳機重試，而不是必須先到設定試聽。這是針對 WebKit 的改善，不保證所有 iPhone/iOS 組合百分之百成功。
2. **朗讀反白會消失**：每個分頁文字節點保留段落識別碼，並在語音開始及每次 boundary 事件中維持標示。
3. **暫停後翻頁，繼續朗讀跳回舊位置**：手動翻頁會重置已暫停的朗讀位置；再次點耳機會從當前畫面頁首開始，不會從原本暫停的位置繼續。若沒有手動翻頁，暫停／繼續仍維持同一朗讀位置。

保留直排/橫排、書架、TXT/EPUB、封面、繁簡轉換、跟隨朗讀、閱讀設定、備份和離線閱讀。

## GitHub Pages 更新

上傳 ZIP 解壓縮後的檔案到原有 Repository 根目錄、取代同名檔案並 Commit。這次的程式變動主要在 `app.js`、`sw.js`、`index.html`、`package.json`，相關測試附於 `tests/`。不要上傳私人小說。

如果 iPhone 仍顯示舊版，可關閉主畫面 App 後重新開啟；新 Service Worker 將更新靜態檔案快取。請勿刪除 PWA 或清空網站資料，以免丟失本機書籍。

## 已知限制

Web Speech API 的中文語音和背景執行受 iOS Safari 限制，關閉螢幕後不保證持續播放；有些 iOS 裝置仍可能需要第二次點擊才能啟動語音。修正版尚未完成真機驗證。
