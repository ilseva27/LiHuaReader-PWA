# 麗華小說 iPhone PWA v1.0.5 — 朗讀手勢與背景音訊實驗

這版以使用者確認能正常閱讀的 **v1.0.4** 為基礎，盡量不修改書架、資料庫、匯入、分頁及繁簡轉換等穩定功能。

## 新增：朗讀中滑動定位

- **由上往下滑**：向後跳 **一個原始段落**，從該段開頭重新朗讀。
- **由下往上滑**：向前跳一個段落，從該段開頭重新朗讀。
- 這裡的「段落」以 TXT 原始換行／EPUB 正文段落為準，不是每個句號切一段。
- 限制：需要在「正在朗讀」或「已暫停」狀態，並在閱讀內文上滑動；選單開啟時不啟用。短點仍保持左右翻頁、中間選單。
- 開啟跟隨朗讀時會跟著新定位翻頁；關閉跟隨也會把畫面定位到本次手動滑動的段落。
- 暫停時滑動只改變位置，不立刻出聲；按耳機後從新位置重新朗讀。
- 目前一次跳一段，**在章節的第一段／最後一段會提示邊界**，不會跨章自動跳轉。

## 背景播放：兩種驗證方式（請看清限制）

1. 「更多設定 → 背景語音實驗（Safari）」：在支援的 Safari 使用 `navigator.audioSession.type = 'playback'`。**這不保證 Web Speech TTS 可以鎖定螢幕朗讀**；若不支援會提示，且不改變原本功能。此項預設關閉，可自行打開測試。Apple/WebKit 各版本行為可能不同。
2. 「更多設定 → 測試背景音檔（MP3／M4A）」：從 iPhone **檔案**選擇一段**已經錄製或生成好的音訊檔**；頁面會出現一個原生 `<audio>` 播放器，並嘗試透過 Media Session 提供鎖屏控制。播放音檔需要自己按播放器的播放鍵。這一條路徑不同於系統 TTS，有機會在鎖定螢幕後繼續播放，但也**不保證所有 iPhone 版本穩定**。

**重要：** 這個 PWA **沒有將小說 TXT／EPUB 自動合成為 MP3**。匯入音檔只是背景播放可行性測試；一個音檔播放完不會自動接下一章，也不會與文字逐句同步。音檔是從手機暫時選取，重新啟動 App 後需要重新選擇，沒有寫入書架資料庫。

## GitHub Pages 更新方式

1. 在 iPhone「麗華小說」的「備份與還原」中先匯出書籍和進度（重要）。
2. 在 Windows 下載 **Update_Files.zip** 並解壓縮。將全部同名檔案更新至現有的 GitHub Repository 根目錄，**不必先刪除全部舊檔、也不要刪除 GitHub Repository**。
3. 等 GitHub Pages 部署完成，用 Safari 開啟原網址並加上 `?v=105`，在書架底部確認顯示 `v1.0.5`。
4. 關閉並重開 iPhone 主畫面的「麗華小說」。不要清除網站資料或刪除 App，以免書籍與進度遺失。
